# Site Web BIKEI - Cabinet de Clarté Stratégique

## 🎨 Caractéristiques du site

J'ai créé un **site web professionnel et moderne** pour le cabinet BIKEI avec les fonctionnalités suivantes :

### ✨ Animations & Effets

- **Animations 3D** : Cartes avec effet de tilt au survol de la souris
- **Effets de parallaxe** : Images qui bougent avec le scroll
- **Transitions fluides** : Tous les éléments s'animent en douceur
- **Effets de scroll révélateur** : Les éléments apparaissent progressivement lors du défilement
- **Gradient animés** : Orbes colorés en arrière-plan qui bougent avec la souris
- **Animations flottantes** : Cartes qui lévitent subtilement
- **Compteurs animés** : Les statistiques s'animent au scroll

### 🎨 Design

- **Palette de couleurs moderne** : Gradients violet/bleu sophistiqués
- **Glassmorphism** : Effets de verre dépoli sur les cartes
- **Typographie premium** : Polices Inter & Outfit de Google Fonts
- **Dark mode élégant** : Design sombre moderne et professionnel
- **Ombres et profondeur** : Effets de profondeur 3D
- **Icons SVG animés** : Icônes vectorielles avec gradients

### 📱 Sections

1. **Hero** - Section d'accueil avec titre accrocheur et statistiques
2. **Mission** - Raison d'être du cabinet
3. **Conviction** - Approche stratégique avec image
4. **Expertise** - Les 4 piliers de l'expertise BIKEI
5. **Offre** - Les 4 services principaux détaillés
6. **Pour qui** - Public cible
7. **Processus** - Ce que reçoivent les clients
8. **Valeur** - Bénéfices et proposition de valeur
9. **CTA** - Appel à l'action avec formulaire de contact
10. **Footer** - Informations de contact et liens

### 📱 Responsive

Le site est **100% responsive** et s'adapte à tous les écrans :
- Desktop (1920px et +)
- Laptop (1024px - 1920px)
- Tablette (768px - 1024px)
- Mobile (320px - 768px)

## 🎨 Personnalisation

Toutes les couleurs, espacements et animations sont définis dans les variables CSS au début de `style.css` :

```css
:root {
    --color-primary: #667eea;
    --color-secondary: #764ba2;
    /* ... etc */
}
```

Vous pouvez facilement modifier ces valeurs pour personnaliser le design.
